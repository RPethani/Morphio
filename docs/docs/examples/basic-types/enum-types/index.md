# Working with Enum Types

Morphio provides comprehensive support for TypeScript enums, allowing you to:
- Serialize both numeric and string enums
- Control serialization format using 'key' or 'value' strategies
- Set default values for enum properties
- Handle invalid enum values gracefully
- Work with string keys during deserialization

## Examples

Choose your preferred approach:
- [Decorator-based Configuration](../enum-types/decorator-based)
- [Schema-based Configuration](../enum-types/schema-based)

Both approaches provide the same functionality, just with different ways of configuring the serialization behavior.
